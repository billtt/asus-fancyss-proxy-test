结果适用于什么流量？

假设 LAN 设备的流量已进入 SHADOWSOCKS 链，且使用 TCP 22 / 80 / 443 / 8080 / 8443。DIRECT 表示在该链 RETURN；后续其他规则仍可能改变路径。PROXY 表示重定向到本机 3333 端口，不代表代理连接一定成功。

规则顺序与检测边界

ignlist → black_list → chnlist → chnroute → white_list → 默认代理

未模拟 PREROUTING 前置规则、设备访问控制、源地址策略、路由器自身 OUTPUT、UDP/QUIC 或 IPv6。DNS/CDN、浏览器 DoH、DNS 缓存以及动态 ipset 可能造成真实访问差异。DNS 查询可能触发 dnsmasq 自身维护动态 ipset；本工具不写入防火墙、ipset 或 fancyss 配置。

只接受当前已验证的完整规则顺序；链改变、集合缺失或检测失败时显示“无法判断”。所有结果为本次 DNS 响应快照，不是域名在全球的全部地址。
